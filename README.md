# BronqAlert — Protótipo Web

Estrutura:

BronqAlert_Projeto/
├── index.html
├── logo.png
├── css/
│   └── style.css

O logo.png é a identidade oficial enviada para o projeto.

Para testar:
1. Abra o index.html no navegador.
2. Para desenvolvimento local, pode usar o Live Server do VS Code.
3. As integrações de mapa e dados são demonstrativas.
